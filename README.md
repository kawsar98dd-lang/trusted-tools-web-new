## 🔐 Server-side Telegram Notifications (Cloudflare Pages Function)

Telegram bot credentials are **server-side secrets** and must never be placed in `assets/js/` or any browser-delivered file.

In Cloudflare Pages → Settings → Environment variables and secrets, add:

- `TELEGRAM_BOT_TOKEN` — the current token generated by BotFather (Secret)
- `TELEGRAM_CHAT_ID` — the destination chat/channel ID (Secret)

The browser calls `POST /api/telegram-notify`; the Cloudflare Pages Function in `functions/api/telegram-notify.js` forwards the notification to Telegram without exposing the bot token to visitors.

> After rotating a token that was previously present in the repository, treat the old token as compromised and do not reuse it. Removing a file does not remove a secret from Git history.

## 🗺️ Sitemap

Run `node generate-sitemap.js` after adding tools. It writes clean (extension-less) URLs that match each page's canonical URL, using `baseUrl` from `assets/js/site-config.js`.

## ✅ Local Regression Tests

Run `node tests/run-tests.js` from the project root (Node.js only, no dependencies). It statically checks tool count, canonical/sitemap consistency, local references, JS/JSON syntax, `_redirects`, `_routes.json`, secrets and stale paths. It is not used by the production site and does not replace browser testing.
