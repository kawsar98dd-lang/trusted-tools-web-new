## 🔐 Server-side Telegram Notifications

Telegram bot credentials are **server-side secrets** and must never be placed in `assets/js/` or any browser-delivered file.

For Netlify deployment, configure these environment variables in the Netlify dashboard:

- `TELEGRAM_BOT_TOKEN` — the current token generated by BotFather
- `TELEGRAM_CHAT_ID` — the destination chat/channel ID

The browser calls `/api/telegram-notify`; the Netlify Function forwards the notification to Telegram without exposing the bot token to visitors.

> After rotating a token that was previously present in the repository, treat the old token as compromised and do not reuse it.
