RFC 5322 Email Extraction

Our engine uses a battle-tested RFC 5322 compliant regex that handles subdomains, plus-addressing (user+tag@domain.com), and international TLDs. No false positives.

International Phone Numbers

Recognises E.164 format, North American NANP, UK, European, and Asian phone patterns. Handles parentheses, dashes, spaces, and country code prefixes like +1, +44, +880.

AI OCR Vision Engine

Powered by Tesseract.js, our OCR engine reads text from screenshots, scanned documents, business cards, and photos. Processes entirely in-browser — never uploads your image.

ZIP Bundle Export

Export all extracted data types into a single ZIP archive using JSZip. Each category gets its own file: emails.txt, phones.txt, urls.txt, ips.txt.

Frequently Asked Questions

Is my data safe and private?

Absolutely. This tool is 100% client-side. Your text, files, and images never leave your browser. No data is sent to any server — not even for OCR, which runs via WebAssembly locally.

What file types does the extractor support?

For text extraction: .txt, .csv, and .json files up to 50MB. For OCR-based image extraction: .jpg, .png, and .webp. You can also paste raw text directly.

How does the Custom Regex feature work?

Enable the "Custom Regex" checkbox and enter any valid JavaScript regular expression pattern (without the surrounding slashes). Add flags like gi for global, case-insensitive matching. The tool validates your regex in real-time.

Can I extract data from multiple files at once?

Yes! The file upload zone supports multi-file selection. All files are read and their contents are concatenated into the text input area before extraction runs.
