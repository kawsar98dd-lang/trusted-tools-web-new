Security Knowledge Base

                


                
                


                    

                        
 What is LSB Steganography?

                        
LSB (Least Significant Bit) steganography works by replacing the least important bit of each color channel value in an image's pixels. Since changing 1 bit out of 8 shifts a color value by only 1 (e.g., 200 → 201), the visual difference is completely imperceptible to the human eye. We use the R, G, and B channels of each pixel, hiding 3 bits per pixel with zero visible change.

                    


                    

                        
 AES-256 Dual-Layer Protection

                        
Before any pixel manipulation occurs, your message is encrypted using AES-256-CBC via the industry-standard CryptoJS library. This means the data hidden in pixels is already ciphertext — completely unreadable without the password. Even if an attacker extracts all pixel data using the same tool, they still cannot recover your message without the correct key.

                    


                    

                        
 Why PNG? The Lossless Requirement

                        
JPEG compression is lossy — it discards "unimportant" data during compression, which is exactly where steganographic data lives (LSBs). This destroys hidden messages. PNG uses lossless compression (DEFLATE), preserving every single bit perfectly. This is why Stegano Vault always exports as .png even if you upload a .jpg.

                    


                    

                        
 Client-Side: Your Data Never Leaves

                        
Every single operation — image reading, encryption, pixel manipulation, and file export — happens entirely within your browser using the HTML5 Canvas API and CryptoJS. No data is transmitted to any server. No logs are kept. The tool works offline after the page loads. You can even air-gap the entire tool on a USB drive.

                    


                    

                        
 Capacity Formula Explained

                        
The maximum number of characters you can encode depends directly on the image's pixel count. Formula: maxChars = Math.floor((width × height × 3) / 8) - 32. The 3 factor accounts for R, G, B channels (3 bits/pixel). The 8 divides bits into bytes. The 32-byte overhead accommodates the AES delimiter and length header we prepend to the data stream.

                    


                    

                        
 Steganalysis Resistance

                        
Since we only modify the LSBs and the hidden data is encrypted (and thus appears as random noise), statistical analysis of the image's color histogram will show minimal anomalies. This makes detection by basic steganalysis tools significantly harder compared to hiding plaintext, which would create detectable patterns in the LSB plane.

                                Can someone detect that my image contains a hidden message?
                                
                            
                            

                                
Visually, no. The changes to individual pixels are too subtle for human vision to perceive. However, a forensic steganalysis tool that examines statistical anomalies in the LSB plane of an image may theoretically detect that steganography was used. To maximize covertness, use large, complex images (photos with lots of detail) and keep your hidden message small relative to the image's total capacity.

                            

                        


                        

                            
                                What happens if I lose my password?
                                
                            
                            

                                
The message is permanently unrecoverable without the password. AES-256 is a symmetric cipher — without the key, brute-forcing is computationally infeasible (2256 possible keys). There is no "forgot password" option, no backdoor, and no recovery mechanism. Store your password safely — we recommend a password manager.

                            

                        


                        

                            
                                Why must I use PNG for decoding?
                                
                            
                            

                                
JPEG is a lossy format — it discards pixel data during compression, destroying the LSB information where your secret is stored. Always share and decode using the lossless PNG file that Stegano Vault exports. If you convert the PNG to JPEG before sharing, the hidden message will be permanently destroyed and unrecoverable.

                            

                        


                        

                            
                                How large of a secret message can I hide?
                                
                            
                            

                                
It depends entirely on your image dimensions. A typical 1920×1080 image (≈2 megapixels) can hide approximately 720,000 bytes (≈720KB) of data. The Capacity Analyzer on the Encode tab shows you the exact maximum in real time after uploading your image. For small messages (passwords, notes), even a 100×100 thumbnail provides plenty of space.

                            

                        


                        

                            
                                Does this tool work offline?
                                
                            
                            

                                
Yes. After the initial page load (which fetches the CSS, JS, and CryptoJS library), all processing is 100% local. You can disable your internet connection and continue encoding/decoding images indefinitely. For maximum security, you can save this page as an HTML file and run it entirely offline on an air-gapped machine.
