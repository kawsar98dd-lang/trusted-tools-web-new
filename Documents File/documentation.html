Installation & Setup

এই প্রজেক্ট সম্পূর্ণ Static (HTML/JS/CSS)। তাই যেকোনো সাধারণ ওয়েব হোস্টে আপলোড করেই কাজ শুরু করা যাবে।

1

ZIP ফাইল Extract করুন

CodeCanyon থেকে ডাউনলোড করা .zip ফাইলটি আপনার কম্পিউটারে Extract করুন। আপনি Code-Canon-Project নামের একটি ফোল্ডার পাবেন।

2

site-config.js কাস্টমাইজ করুন

আপলোড করার আগে assets/js/site-config.js খুলুন এবং আপনার সাইটের নাম, ডোমেইন, এবং API কী গুলো যুক্ত করুন।

3

হোস্টিংয়ে আপলোড করুন

ফোল্ডারের সব ফাইল আপনার হোস্টিংয়ের public_html বা htdocs ফোল্ডারে আপলোড করুন (cPanel File Manager বা FTP ব্যবহার করে)।

4

আপনার ডোমেইন ভিজিট করুন

ব্রাউজারে আপনার ডোমেইন টাইপ করুন — সাইট এখন Live! কোনো Database Setup বা Server Configuration লাগবে না।

Local Testing করতে চাইলে: সরাসরি ফাইল ডাবল-ক্লিক করে ব্রাউজারে খুলবেন না — এতে কিছু JavaScript কাজ নাও করতে পারে। পরিবর্তে VS Code Live Server extension বা Spck Editor-এর built-in preview ব্যবহার করুন।

Folder Structure

ফাইলগুলো কোথায় আছে সেটা জানলে কাস্টমাইজ করা অনেক সহজ হবে।

Root/ ├── index.html ← মূল হোমপেজ ├── documentation.html ← এই ফাইল │ ├── assets/ ← সব গ্লোবাল রিসোর্স এখানে │ ├── css/ │ │ ├── global.css ← রং, ফন্ট, থিম ভেরিয়েবল │ │ └── tools-template.css ← সব টুলের শেয়ার্ড স্টাইল │ ├── js/ │ │ ├── site-config.js ← ✅ আপনার প্রধান কনফিগ ফাইল │ │ ├── global.js ← হেডার/ফুটার ইনজেকশন │ │ ├── tools-data.js ← হোমপেজ টুল কার্ড ডেটা │ │ ├── analytics-loader.js ← Google Analytics কোড │ │ ├── ads-manager.js ← AdSense/Banner Ads │ │ ├── comments.js ← কমেন্ট সিস্টেম (এডিট করবেন না) │ │ └── related-tools.js ← সম্পর্কিত টুল │ ├── img/ ← লোগো, OG Banner ইমেজ │ └── library/ ← Font Awesome (লোকালি হোস্টেড) │ ├── components/ ← হেডার ও ফুটার HTML ├── pages/ ← About, Contact, Privacy পেজ │ └── tools/ ← সব টুল ক্যাটাগরি অনুযায়ী ├── calc/ ← Calculators (Age, BMI, etc.) ├── dev/ ← Developer Tools ├── img/ ← Image Tools ├── media/ ← Audio / Media Tools ├── text/ ← Text & Font Tools └── sec/ ← Security Tools
সোনালী নিয়ম: শুধু site-config.js, global.js, tools-data.js, ads-manager.js এবং global.css ফাইল এডিট করুন। comments.js কখনো এডিট করবেন না।

site-config.js — Master Config Guide

এটি আপনার সবচেয়ে গুরুত্বপূর্ণ ফাইল। সাইটের প্রতিটি ফিচার এই একটি ফাইল থেকে কনফিগার করা হয়। ফাইলটি আছে: assets/js/site-config.js

ধাপ ১ — Basic Information (বেসিক তথ্য)

ফাইলটি খুলুন এবং প্রথমে নিচের অংশটি আপনার তথ্য দিয়ে পূরণ করুন:

assets/js/site-config.js
window.SITE_CONFIG = {

    // ── আপনার সাইটের নাম এবং তথ্য
    brandName   : "আপনার সাইটের নাম",
    author      : "আপনার নাম",
    baseUrl     : "https://yourdomain.com",  // শেষে / দেবেন না

    // ── SEO Description
    defaultDescription : "আপনার সাইটের SEO বিবরণ",
    themeColor         : "#0d1117",  // ব্রাউজার থিম রং

    // ── যোগাযোগ
    contactEmail : "your@email.com",
    mainSiteUrl  : "https://yourdomain.com",
};

ধাপ ২ — Social Media (সোশ্যাল মিডিয়া)

assets/js/site-config.js
    facebookAppId : "আপনার Facebook App ID",
    twitterHandle : "@YourTwitterHandle",
    ogSiteName    : "আপনার সাইটের পুরো নাম",
Facebook App ID না থাকলে facebookAppId খালি রাখুন ("")। Social Sharing তবুও কাজ করবে। Twitter Handle না থাকলেও একই।

সব প্যারামিটারের তালিকা

Parameter Type কী করে
brandNamestringসাইটের নাম, হেডারে দেখায়
authorstringলেখকের নাম
baseUrlstringআপনার ডোমেইন (https সহ)
defaultDescriptionstringGoogle-এ যে বিবরণ দেখাবে
themeColorhex colorমোবাইলে ব্রাউজার ট্যাবের রং
facebookAppIdstringFacebook sharing এর জন্য App ID
twitterHandlestringTwitter/X প্রোফাইল হ্যান্ডেল
ogSiteNamestringOpen Graph-এ সাইটের নাম
defaultOGImagepathশেয়ারিং-এ যে ছবি দেখাবে
contactEmailemailContact পেজে দেখানো ইমেইল

Branding & Colors

সাইটের নাম, লোগো এবং রং পরিবর্তন করার নির্দেশিকা।

সাইটের নাম পরিবর্তন করুন

হেডার এবং ফুটার ডায়নামিকভাবে assets/js/global.js ফাইল থেকে তৈরি হয়। নাম পরিবর্তন করতে:

assets/js/global.js — loadGlobalHeader ফাংশন খুঁজুন
// এই অংশটি খুঁজুন এবং Your Brand Name পরিবর্তন করুন:
headerEl.innerHTML = `
    <a href="${root}index.html" class="header-logo">
        <i class="fa-solid fa-shield-halved"></i>
        Your Brand <span>Name</span>
    </a>
`;

গ্লোবাল রং (Theme Colors) পরিবর্তন করুন

সাইটের সব রং assets/css/global.css ফাইলের উপরে :root ভেরিয়েবলে থাকে:

assets/css/global.css
:root {
    /* প্রধান Accent রং — সবচেয়ে বেশি ব্যবহৃত হয় */
    --accent-cyan:   #00f3ff;  /* নীল/সায়ান গ্লো রং */

    /* ব্যাকগ্রাউন্ড */
    --bg-primary:    #0d1117;  /* মূল ব্যাকগ্রাউন্ড */
    --bg-secondary:  #161b22;  /* কার্ড ব্যাকগ্রাউন্ড */

    /* টেক্সট রং */
    --text-main:     #c9d1d9;  /* মূল টেক্সট */
    --text-muted:    #8b949e;  /* হালকা টেক্সট */
}
টিপস: শুধু --accent-cyan রং পরিবর্তন করলেই সাইটের মূল থিম রং বদলে যাবে। Hex color picker এর জন্য htmlcolorcodes.com ব্যবহার করতে পারেন।

Managing Tools (tools-data.js)

হোমপেজের টুল গ্রিড এবং "Related Tools" সেকশন ডায়নামিকভাবে assets/js/tools-data.js থেকে তৈরি হয়। এখানে প্রতিটি টুলের তথ্য একটি object হিসেবে থাকে।

টুলের তথ্য পরিবর্তন করুন

প্রতিটি টুলের structure এরকম দেখতে:

assets/js/tools-data.js — একটি টুলের structure
{
    link:         "tools/calc/age-calculator.html",  // টুলের URL পাথ
    category:     "calc",                         // ফিল্টার ক্যাটাগরি
    classes:      "tool-card",                    // CSS ক্লাস
    themeColor1:  "#00e5ff",                      // কার্ডের প্রাইমারি রং
    themeColor2:  "#d124ff",                      // কার্ডের সেকেন্ডারি রং
    dataName:     "age calculator keywords...",    // সার্চ keywords
    html: `...`                                      // কার্ডের ভিজুয়াল HTML
}

নতুন টুল যোগ করার পদ্ধতি

1

যেকোনো বিদ্যমান টুলের object কপি করুন

tools-data.js খুলুন, শেষের একটি object {...} কপি করুন।

2

link, category, dataName আপডেট করুন

নতুন টুলের URL, ক্যাটাগরি (calc/sec/img/dev/text/media), এবং সার্চ কীওয়ার্ড দিন।

3

দুটি থিম রং বেছে নিন

themeColor1 ও themeColor2-এ দুটি Hex রং দিন। বাকি সব CSS স্বয়ংক্রিয়ভাবে তৈরি হবে।

Zero CSS! দুটি রং দিলেই কার্ডের badge, icon, title — সব কিছু সেই রংয়ে স্বয়ংক্রিয়ভাবে রঙিন হয়। নতুন CSS লেখার প্রয়োজন নেই।

Ads & Analytics Configuration

সেন্ট্রালাইজড সিস্টেম — একটি ফাইল পরিবর্তনেই সব ৬০+ টুল পেজে ads ও analytics যুক্ত হবে।

Google Analytics যোগ করুন

assets/js/analytics-loader.js খুলুন এবং আপনার Google Analytics snippet পেস্ট করুন:

assets/js/analytics-loader.js
// Google Analytics snippet এখানে paste করুন
(function() {
    const script = document.createElement('script');
    script.src = 'https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX';
    script.async = true;
    document.head.appendChild(script);

    window.dataLayer = window.dataLayer || [];
    function gtag(){ dataLayer.push(arguments); }
    gtag('js', new Date());
    gtag('config', 'G-XXXXXXXXXX'); // ← আপনার Measurement ID
})();

AdSense / Banner Ads যোগ করুন

assets/js/ads-manager.js খুলুন এবং placeholder গুলো আপনার AdSense কোড দিয়ে প্রতিস্থাপন করুন:

assets/js/ads-manager.js
const AD_UNITS = {
    'top-banner':    '<!-- আপনার AdSense Top Banner Code -->',
    'bottom-banner': '<!-- আপনার AdSense Bottom Banner Code -->'

In-feed Comment Ads (site-config.js থেকে)

কমেন্ট সেকশনে প্রতি N টি কমেন্টের পর Ad দেখাতে site-config.js এডিট করুন:

assets/js/site-config.js → commentSystem.ads
ads: {
    enabled:      true,          // true = চালু, false = বন্ধ
    injectAfterN: 5,             // প্রতি ৫টি কমেন্টের পর Ad আসবে
    adHTML: `
        <ins class="adsbygoogle"
             data-ad-client="ca-pub-XXXXXXXXXXXXXXXX"
             data-ad-slot="XXXXXXXXXX"></ins>
    `
}

Firebase Setup (Comment System)

Comment System চালু করতে Firebase প্রয়োজন। এটি বিনামূল্যে পাওয়া যায় এবং সেটআপ সহজ।

গুরুত্বপূর্ণ: Comment System ব্যবহার করতে চাইলে Firebase অবশ্যই কনফিগার করতে হবে। না করলে কমেন্ট সেকশন কাজ করবে না।
1

Firebase Console এ যান

console.firebase.google.com এ Google Account দিয়ে Login করুন এবং "Add Project" ক্লিক করুন।

2

Web App যোগ করুন

Project তৈরির পর, Project Settings → "Add App" → Web (</>) আইকনে ক্লিক করুন। একটি App Name দিন।

3

Config কপি করুন

Firebase আপনাকে একটি config object দেবে। সেখান থেকে প্রতিটি মান site-config.js-এর firebase অংশে বসান।

4

Firestore Database চালু করুন

Firebase Console → Firestore Database → "Create Database" → "Start in production mode" সিলেক্ট করুন।

5

Google Authentication চালু করুন

Firebase Console → Authentication → Sign-in Method → Google চালু করুন।

assets/js/site-config.js → commentSystem.firebase
firebase: {
    apiKey            : "AIzaSy...",          // Firebase Console থেকে
    authDomain        : "your-app.firebaseapp.com",
    projectId         : "your-project-id",
    storageBucket     : "your-app.firebasestorage.app",
    messagingSenderId : "000000000000",
    appId             : "1:000000000000:web:..."
},

Admin ইমেইল সেট করুন

assets/js/site-config.js
// আপনার Google ইমেইল এখানে দিন — Admin সুবিধা পাবেন

ImgBB API — Image Attachments

কমেন্টে ইমেজ আপলোড ফিচারটি ImgBB ব্যবহার করে। ImgBB বিনামূল্যে ছবি হোস্ট করে।

Feature 1 Image Attachments

Optional

ব্যবহারকারীরা কমেন্টে ছবি যুক্ত করতে পারবে। ছবিগুলো ImgBB-তে সংরক্ষিত হবে।

1

ImgBB API Key নিন

api.imgbb.com এ যান → Login করুন → "Get API Key" ক্লিক করুন।

2

site-config.js এ Key বসান

নিচের কোডে imgbbApiKey-এ আপনার API Key বসান।

site-config.js → commentSystem.imageAttachments
imageAttachments: {
    enabled       : true,             // চালু/বন্ধ
    imgbbApiKey   : "আপনার ImgBB Key", // এখানে Key বসান
    expiration    : 0,                // 0 = ছবি কখনো মুছবে না
    maxSizeMB     : 5,                // সর্বোচ্চ ফাইল সাইজ (MB)
    acceptedTypes : "image/jpeg,image/png,image/gif,image/webp"
},
ImgBB Key না থাকলে enabled: false করে রাখুন। Image upload button তখন দেখাবে না।

Cloudinary — Voice Notes

কমেন্টে ভয়েস রেকর্ডিং সুবিধা দেয় Cloudinary। এটিও বিনামূল্যে শুরু করা যায়।

Feature 2 Voice Notes with AI Enhancement

Optional

ব্যবহারকারীরা সর্বোচ্চ ৬০ সেকেন্ড পর্যন্ত ভয়েস নোট রেকর্ড করে কমেন্টে যুক্ত করতে পারবে। "Clean Voice" বাটনে ক্লিক করলে Web Audio API দিয়ে গোলমাল ফিল্টার হবে।

1

Cloudinary Account তৈরি করুন

cloudinary.com এ Sign Up করুন (বিনামূল্যে)।

2

Upload Preset তৈরি করুন

Dashboard → Settings → Upload → "Add upload preset" → Signing Mode: Unsigned রাখুন। Preset Name দিন (যেমন: ttw_audio_preset)।

3

Cloud Name কপি করুন

Dashboard-এ আপনার Cloud Name দেখতে পাবেন।

site-config.js → commentSystem.voiceNotes
voiceNotes: {
    enabled            : true,
    cloudName          : "আপনার Cloudinary Cloud Name",
    uploadPreset       : "ttw_audio_preset",   // Preset নাম
    maxDurationSeconds : 60,                    // সর্বোচ্চ রেকর্ডিং সময়
    enableVoiceEnhance : true                   // Clean Voice ফিচার
},

FAQ & Troubleshooting

সাধারণ সমস্যা এবং তাদের সমাধান — কোনো টেকনিক্যাল জ্ঞান ছাড়াই।

Q সাইট আপলোড করার পর Header বা Footer দেখাচ্ছে না কেন?
এটি সাধারণত ঘটে যখন global.js ফাইলটি সঠিকভাবে লোড হয় না। নিশ্চিত করুন যে আপলোডের সময় assets/js/global.js ফাইলটি সঠিক স্থানে আছে। local থেকে টেস্ট করলে Live Server ব্যবহার করুন — সরাসরি index.html ডাবল-ক্লিক করে খুলবেন না।
Q কমেন্ট সেকশন দেখাচ্ছে না বা Error দিচ্ছে?
Firebase কনফিগারেশন সঠিক কিনা দেখুন। site-config.js-এ firebase অবজেক্টের সব মান সঠিকভাবে বসানো আছে কিনা যাচাই করুন। এছাড়া Firebase Console থেকে Firestore এবং Google Authentication চালু আছে কিনা নিশ্চিত করুন। আপনার Domain টি Firebase Authorized Domains-এ যোগ করুন (Authentication → Settings → Authorized Domains)।
Q ছবি আপলোড হচ্ছে না?
দুটি কারণ হতে পারে: ১) ImgBB API Key সঠিক নয় — api.imgbb.com থেকে নতুন Key নিয়ে সঠিকভাবে বসান। ২) ফাইলের সাইজ maxSizeMB সীমার বেশি — maxSizeMB এর মান বাড়িয়ে দিন।
Q Telegram নোটিফিকেশন আসছে না?
তিনটি জিনিস নিশ্চিত করুন: ১) Bot Token সঠিক কিনা, ২) Chat ID সঠিক কিনা (নেগেটিভ নম্বরও হতে পারে), ৩) আপনি Bot-কে প্রথমে কোনো message পাঠিয়েছেন কিনা। Bot-কে একবার /start কমান্ড পাঠান।
Q হোমপেজে টুল কার্ডের নাম/আইকন পরিবর্তন করব কীভাবে?
assets/js/tools-data.js খুলুন। যে টুলের নাম পরিবর্তন করতে চান, সেটির html এর মধ্যে tool-title div খুঁজুন এবং নাম বদলে দিন। আইকন বদলাতে Font Awesome-এর ক্লাস পরিবর্তন করুন (যেমন fa-calculator)।
Q নতুন টুল পেজ কি সার্চ ফিল্টারে দেখাবে?
হ্যাঁ, কিন্তু আপনাকে tools-data.js-এ নতুন টুলের dataName-এ সঠিক keywords যোগ করতে হবে। ব্যবহারকারী যখন সেই keywords লিখে সার্চ করবে, তখন কার্ডটি ফলাফলে আসবে।
Q Voice Notes ফিচার মোবাইলে কাজ করছে না?
মোবাইল ব্রাউজার মাইক্রোফোনের অনুমতি চাইবে — অবশ্যই Allow করুন। iOS Safari-তে HTTPS ছাড়া মাইক কাজ করে না, তাই সাইটটি HTTPS-এ হোস্ট করা নিশ্চিত করুন। Cloudinary cloudName এবং uploadPreset সঠিক আছে কিনা যাচাই করুন।
Q Google AdSense Ads দেখাচ্ছে না?
প্রথমত নিশ্চিত করুন আপনার AdSense account approved এবং ca-pub-XXXXXX code সঠিক। নতুন সাইটে Ad দেখাতে ২৪-৪৮ ঘন্টা সময় লাগতে পারে। AdBlocker থাকলে টেস্ট করার সময় বন্ধ রাখুন।
Q সাইটের রং পরিবর্তন করলে কিছু টুলে পুরনো রং থাকছে?
assets/css/global.css-এর :root-এ রং বদলালে সব পেজে প্রভাব পড়বে। কিন্তু কিছু টুল কার্ড tools-data.js-এ themeColor1 এবং themeColor2 দিয়ে নিজস্ব রং ব্যবহার করে — সেগুলো আলাদাভাবে পরিবর্তন করতে হবে।
